[![CI](https://github.com/baileyrd/rusty_config/actions/workflows/ci.yml/badge.svg)](https://github.com/baileyrd/rusty_config/actions/workflows/ci.yml)

A zero-dependency, `#![no_std]` INI and Key-Value configuration file parser for Rust.

`rusty_config` parses `.ini` and `.conf` configuration files into section blocks and key-value maps without requiring heavy external dependencies.
